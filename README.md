# Masroufi | مصروفي — Starter V1

واجهة أولية لتسجيل الدخل والمصاريف صوتياً أو يدوياً، مع تخزين محلي، عمليات متكررة، رسوم بيانية، CSV ونسخة JSON احتياطية.

## التشغيل
- افتح `index.html` مباشرة للتجربة الأساسية. قد لا يعمل التسجيل الصوتي أو PWA عند فتح الملف مباشرة.
- للتجربة الكاملة شغّل خادماً محلياً من مجلد المشروع، مثلاً:
  - Python: `python -m http.server 8000`
  - ثم افتح `http://localhost:8000`
- للنشر استخدم Cloudflare Pages وارفع محتويات المجلد كما هي.

## الخصوصية والقيود الحالية
- العمليات والإعدادات محفوظة في `localStorage` على الجهاز والمتصفح الحالي.
- لا توجد حسابات ولا مزامنة بين الأجهزة في هذه النسخة؛ كل مستخدم يحتاج ملف بيانات/متصفحاً منفصلاً.
- التعرف الصوتي يستخدم Web Speech API إن كان متاحاً. دعم `ar-DZ` يختلف حسب المتصفح ومزود خدمة التعرف، وقد يحتاج الإنترنت. راجع إعدادات وخصوصية المتصفح قبل استخدامه.
- مكتبة Chart.js وخط Cairo يتم تحميلهما من CDN؛ لذلك يحتاج الرسم البياني والخط المخصص اتصالاً أولياً بالإنترنت. بقية الواجهة مخزنة عبر Service Worker بعد أول زيارة.
- محلل الكلام في V1 بسيط وتجريبي: يستخرج الأرقام وبعض الكلمات المفتاحية فقط. يجب مراجعة النص والبيانات قبل الحفظ، ولا تعتمد عليه كمعالجة لغوية دقيقة للهجة الجزائرية.
- لا تسجل التطبيق كلمات مثل «مليون» أو «ألف» بمعاملاتها الحسابية بشكل موثوق بعد؛ أدخل المبلغ يدوياً عند عدم التأكد.

## الملفات
- `index.html`: بنية الواجهة.
- `styles.css`: تصميم داكن وفاتح ومتجاوب.
- `app.js`: التخزين، العمليات، الصوت، التقارير والتصدير.
- `manifest.webmanifest` و`sw.js`: خصائص PWA والتخزين المؤقت.

## قبل الاستخدام الحقيقي
أضف قاعدة بيانات IndexedDB مع ترحيل آمن من localStorage، اختبارات للمحلل الصوتي، دعم عملات لكل عملية، وإمكانية قفل التطبيق/تصدير مشفر إذا كانت البيانات حساسة.
