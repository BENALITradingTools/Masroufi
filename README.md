# Masroufi — مصروفي (V1.3)

تطبيق ويب عربي (PWA) لتسجيل الدخل والمصاريف بالصوت أو يدوياً. البيانات محلية على الجهاز.

## الميزات
- **تسجيل صوتي بالضغط المستمر**: يعمل الميكروفون فقط أثناء الضغط على الزر ويتوقف عند تركه (ضغطة أقل من 0.4 ثانية تُلغى). لا بدء تلقائي ولا إعادة تشغيل. حد أقصى 60 ثانية. يعمل أيضاً بلوحة المفاتيح (Space/Enter مع الاستمرار).
- حفظ العمليات الصوتية مباشرة (دون تأكيد) مع زر **تراجع** لمدة 6 ثوانٍ. إن لم يُستخرج مبلغ ونوع واضحان لا يُحفظ شيء.
- **تعديل** أي عملية، وحذفها مع **تراجع**.
- **التنقل بين الأشهر**: الرئيسية والعمليات والتقارير تتبع الشهر المحدد.
- **ميزانية شهرية**: شريط تقدم، المتبقي، المتاح يومياً، تقدير نهاية الشهر (استقراء خطي)، وتنبيه عند 80% وعند التجاوز.
- **العمليات**: بحث، تصفية بالنوع، نطاق (الشهر/الكل)، فرز، وملخص للنتائج.
- **التقارير**: نسبة الادخار، أكبر مصروف، مقارنة بالشهر السابق، اتجاه آخر 6 أشهر، المصاريف حسب الفئة بالنسبة المئوية، وطباعة/PDF.
- عمليات متكررة (يومي/أسبوعي/شهري/سنوي) مع الحفاظ على يوم الشهر الأصلي (31 → 28 → 31).
- اقتراح الأوصاف من عملياتك السابقة عند الإدخال اليدوي.
- نسخ احتياطي: نسخ تلقائية في IndexedDB (آخر 12) **مع قائمة استعادة**، وتنزيل/استيراد JSON. يُحفظ تلقائياً لقطة من بياناتك الحالية قبل أي استعادة. الاستيراد يتحقق من السجلات ويتجاهل غير الصالح منها.
- تصدير CSV، وضع داكن/فاتح، PWA.

## ما تغيّر في V1.3 (إصلاحات)
- الوصف الصوتي كان يُشوَّه بحذف الحروف المفردة من داخل الكلمات (بنزين ← نزين). يُحذف الآن الكلمات الكاملة فقط.
- التواريخ تُحسب بالتوقيت المحلي بدل UTC (كان يُسجَّل تاريخ أمس بين 00:00 و01:00 بتوقيت الجزائر).
- متوسط المصروف اليومي كان يقسم مصاريف كل الفترات على رقم اليوم؛ أصبح للشهر المحدد.
- مكتبة Chart.js مثبّتة على إصدار محدد (4.5.1)، وتم رفع إصدار كاش الـService Worker إلى v3 لتصل التحديثات للمستخدمين.

## التشغيل المحلي
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## قيود معروفة
- التعرف الصوتي يعتمد على المتصفح: دعم `ar-DZ` ودقته تختلف، وقد يُرسل الصوت إلى خدمة المتصفح. جرّب عباراتك الفعلية قبل الاعتماد عليه.
- المحلل لا يحفظ عملية بلا كلمة تحدد نوعها (مثل «خلصت»، «دخلتلي»). قول «بنزين 2000» وحده لا يُحفظ.
- لا يفصل المحلل بين عمليتين إلا عند «و» قبل المبلغ التالي (مثال: «خلصت 150 قهوة و 2000 بنزين»). عبارة تجمع دخلاً ومصروفاً في جملة واحدة لا تُحفظ.
- الأرقام المنطوقة المركبة المقترنة ببادئة (مثل «بمية وخمسين») لا تُفهم.
- تغيير العملة يبدّل الرمز فقط ولا يحوّل المبالغ.
- التصنيف يساوي الوصف، لذا «بنزين» و«بنزين السيارة» فئتان مختلفتان في التقارير.
- النسخ التلقائية داخل المتصفح؛ مسح بيانات الموقع يحذفها. احتفظ بنسخة JSON خارجية.
