# مصروفي Masroufi — V1.4

تطبيق ويب/PWA لتسجيل الدخل والمصاريف، مع تسجيل صوتي بالضغط المستمر وإرسال التسجيل بعد رفع الإصبع إلى خادم التطبيق لتفريغه إلى نص بواسطة OpenAI Audio API.

## ما الجديد في V1.4
- التسجيل الفعلي عبر `getUserMedia` و`MediaRecorder` بدلاً من الاعتماد على SpeechRecognition في المتصفح.
- اضغط مطولاً على زر الميكروفون، وتحدث، ثم ارفع إصبعك لإيقاف التسجيل وبدء التفريغ.
- يدعم اختيار MIME المناسب للمتصفح تلقائياً (مثل MP4/M4A في Safari وWebM في Chrome عند توفره).
- مفتاح OpenAI محفوظ في الخادم فقط ولا يظهر في ملفات المتصفح.
- يحفظ العمليات تلقائياً إذا استخرج المحلل مبلغاً ونوعاً (دخل/مصروف)؛ وإلا لا يحفظ شيئاً.
- تبقى بيانات الدخل والمصاريف في تخزين المتصفح المحلي، ولا تُرسل إلى مزود التفريغ.

## تشغيل محلي
يتطلب Node.js 20 أو أحدث ومفتاح API:

```bash
npm install
cp .env.example .env
# ضع OPENAI_API_KEY الحقيقي في .env
npm start
```

افتح `http://localhost:3000`. الوصول إلى الميكروفون يتطلب HTTPS في النشر (localhost استثناء للتطوير).

## النشر على Render
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. أنشئ Web Service على Render من المستودع، وسيقرأ `render.yaml`.
3. في Environment أضف `OPENAI_API_KEY` كمفتاح سري. لا تضع المفتاح في `app.js` أو GitHub.
4. افتح رابط HTTPS الناتج واسمح باستخدام الميكروفون.

## الخصوصية والتكلفة
- ملف الصوت يرسل إلى خادمك ثم إلى OpenAI لتفريغه؛ لا يخزنه هذا الخادم عمداً بعد انتهاء الطلب.
- البيانات المالية لا تُرسل إلى OpenAI؛ النص الناتج يعالج محلياً في المتصفح.
- خدمة التفريغ مدفوعة بحسب مدة الصوت. تعرض صفحة أسعار OpenAI حالياً سعراً تقديرياً لنموذج `gpt-transcribe` قدره 0.0045 دولار للدقيقة؛ الأسعار قابلة للتغيير.
- لا يوجد ضمان مسبق لدقة اللهجة الجزائرية. يجب اختبار جمل من لهجتك، خصوصاً الأرقام وأسماء الأشياء، وعدم اعتبار الإدخال الصوتي محاسبياً معصوماً من الخطأ.

## النسخ الاحتياطي
النسخ الدورية تبقى داخل IndexedDB في المتصفح وعلى الجهاز نفسه. نزّل نسخة JSON يدوياً واحتفظ بها خارج المتصفح لتجنب فقدانها عند مسح بيانات الموقع.

## ملاحظات
- Speech-to-text الحالي لا يفرض لغة `ar-DZ` كرمز API لأن النموذج قد لا يقبل رمز اللهجة الإقليمي؛ يُرسل توجيه سياقي باللهجة الجزائرية ويجب تقييم النتائج عملياً.
- واجهة الويب تحتاج اتصالاً بالإنترنت عند التفريغ الصوتي.
