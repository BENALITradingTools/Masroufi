# Masroufi — مصروفي (V1.1)

تطبيق ويب عربي لتسجيل الدخل والمصاريف بالصوت أو يدوياً.

## الميزات
- محاولة التعرف الصوتي باللغة `ar-DZ` مع استنتاج نوع العملية (دخل/مصروف) من صياغة الكلام.
- مراجعة البيانات قبل الحفظ.
- التصنيف يساوي الوصف تلقائياً؛ لا توجد قائمة تصنيفات منفصلة.
- عمليات متكررة، رسوم بيانية، بحث، وتصدير CSV.
- تخزين محلي، ونسخ احتياطي تلقائي دوري داخل IndexedDB على الجهاز، مع الاحتفاظ بآخر 12 نسخة.
- تنزيل/استيراد نسخة JSON يدوياً.
- وضع داكن وفاتح وPWA.

## التشغيل المحلي
يتطلب خادماً محلياً حتى تعمل ميزات PWA وواجهات التخزين على نحو صحيح:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النسخ الاحتياطي
النسخ التلقائية تُحفظ داخل قاعدة IndexedDB الخاصة بالتطبيق في المتصفح. تعمل عند فتح التطبيق، وعند إجراء تغييرات، وتُفحص دورياً أثناء بقاء التطبيق مفتوحاً. اختر كل يوم أو 7 أيام أو 30 يوماً. لا يستطيع موقع ويب حفظ ملفات تلقائياً في مجلد عادي بالجهاز دون إذن صريح من المستخدم؛ لذلك يوجد أيضاً تنزيل JSON يدوي. مسح بيانات المتصفح أو حذف بيانات الموقع قد يحذف النسخ المحلية، لذا احتفظ بنسخة خارجية دورياً.

## الصوت
يستخدم التطبيق SpeechRecognition إن كان المتصفح يدعمه. قد يرسل المتصفح الصوت إلى مزود التعرف الخاص به؛ دعم `ar-DZ` ودقة فهم اللهجة يختلفان حسب المتصفح والجهاز والاتصال. المحلل الحالي تجريبي ويجب اختبار أمثلة اللهجة الحقيقية قبل الاعتماد المالي عليه. كل عملية صوتية تفتح نموذج مراجعة ولا تحفظ تلقائياً.
